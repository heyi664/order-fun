HYEEE Agent Hub · 项目架构

前端网关、Spring Boot 业务服务、缓存/数据库、RocketMQ 异步订单与 Python Agent 调用关系

请求入口

  • Nginx 提供静态页面并将 /api 代理到 Java。
  • 登录会话由 Redis 中的 login:token:* 校验。
  • 社区、账号、Token 包查询均同步返回。

Token 包秒杀链路

  • 入口从 Redis 获取券配置，Lua 原子扣 Redis 库存并校验限购。
  • Java 同步等待 Broker 接收确认，再向客户端返回下单成功。
  • Consumer 异步完成 MySQL 最终库存扣减与订单写入。

AI 对话链路

  • 浏览器请求先到 Java，避免直接暴露 Agent 服务。
  • Java 通过 AGENT_SERVICE_URL 调 Python RAG Agent。
  • Agent 结果由 Java 转发至前端，支持流式响应。
